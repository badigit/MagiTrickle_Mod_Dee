## Главное

**Автообновление прямо из веб-интерфейса.** MagiTrickle раз в сутки тихо сверяется с последним релизом форка, а кнопка обновления в интерфейсе скачивает и ставит новую версию в фоне (лог — `/tmp/magitrickle_update.log`). Сравнение версий понимает dev-сборки (`~git…` считается ниже чистого релиза того же номера), так что и с ручной сборки обновление предложится корректно. Ручная установка через `install.sh` по-прежнему работает.

## Маршрутизация

- **interface-режим: долгие сессии больше не рвутся.** Решение о маршруте теперь фиксируется на всё соединение через conntrack (`CONNMARK save/restore`, restore — только для клиентского направления). Раньше каждый пакет переспрашивал ipset: как только IP выпадал из набора по DNS TTL, длинная загрузка/SSH/WebSocket получали разрыв. Поведение проверено интеграционным тестом с живым демоном: established-соединение переживает полную вычистку ipset, ответный трафик идёт клиенту корректно.
- **Детерминированный арбитраж при пересечении правил.** Если один IP попадает в наборы нескольких групп, во всех режимах (tproxy / interface / direct) выигрывает **первая группа по порядку списка** — единое правило «выше в списке = побеждает». Раньше в interface-режиме исход был случайным (побеждала последняя группа). Порядок закреплён и для доменных правил (trie → wildcard → regex, базовые группы приоритетнее подписок).
- **direct-режим гарантированно перебивает группы.** При пересечении IP трафик direct-группы идёт мимо VPN и не утягивается в прокси другой группы — включая уже установленные соединения.
- **Реактивный маршрут интерфейса.** Если VPN/PPP/DHCP-интерфейс получает адрес и шлюз уже после поднятия, маршрут группы пересоздаётся автоматически (раньше требовался рестарт).

## DNS и стабильность

- Закрыт кластер состояний гонки вокруг изменения конфигурации (единый мьютекс на все мутации) — устраняет редкие рассинхроны и потенциальные паники при одновременных правках через API/интерфейс.
- Устранена гонка в пуле соединений DNS-прокси (закрытие пула против выдачи/возврата соединения).
- Кэш DNS отдаёт копии адресов — исключено случайное изменение записей кэша на месте.
- При активном drop AAAA-ответы больше не протекают в nftset.

## Интерфейсы и наблюдаемость

- Авто-тест доступности IP больше не запускается для входящих интерфейсов (только для исходящих/аплинков).
- Захваченные домены отображаются в веб-интерфейсе в реальном времени.

## Под капотом

- Интеграционный тест interface-режима на network namespaces: реальный демон, живой трафик, проверка reply-path, переживания DNS TTL и арбитража групп.
- Юнит-тесты арбитража доменов (порядок групп, приоритет слоёв) и сравнения версий апдейтера.

---

**Установка / обновление на Keenetic (Entware):**

```sh
opkg update && opkg install wget-ssl ca-certificates
wget -qO- https://raw.githubusercontent.com/badigit/MagiTrickle_mod_badigit/mod_badigit/scripts/install.sh | sh
```

Начиная с этого релиза обновляться можно прямо из веб-интерфейса — кнопкой «Обновить».
