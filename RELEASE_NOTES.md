## Главное

**Автообновление прямо из веб-интерфейса.** Появилась встроенная проверка и установка обновлений форка: MagiTrickle раз в сутки тихо сверяется с последним релизом (`badigit`), а кнопка обновления в интерфейсе скачивает и запускает установку в фоне. Лог процесса — в `/tmp/magitrickle_update.log`. Ручная установка через `install.sh` по-прежнему работает.

## Маршрутизация

- **interface-режим: долгие сессии больше не рвутся.** Добавлена общая mangle-преамбула с `CONNMARK --restore-mark`: решение о маршруте фиксируется на всё соединение через conntrack. Раньше каждый пакет переспрашивал ipset — как только IP выпадал из набора по DNS TTL, длинная качалка/SSH/WebSocket получали разрыв. Теперь маршрут держится до конца соединения.
- **Детерминированный арбитраж при пересечении правил.** Если один IP попадает в наборы нескольких групп, теперь во всех режимах (tproxy / interface / direct) выигрывает **первая группа по порядку списка** — единое правило «выше в списке = побеждает». Раньше в interface-режиме исход был случайным (побеждала последняя группа).
- **direct-режим корректно перебивает группы.** При пересечении IP трафик, попавший в direct-группу, гарантированно идёт мимо VPN, а не утягивается в прокси другой группы.
- **Реактивный маршрут интерфейса.** Если VPN/PPP/DHCP-интерфейс получает адрес и шлюз уже после поднятия, маршрут группы пересоздаётся автоматически (раньше требовался рестарт).

## DNS и стабильность

- Закрыт кластер состояний гонки вокруг изменения конфигурации (единый мьютекс на все мутации) — снимает редкие рассинхроны и потенциальные паники при одновременных правках через API.
- Устранена гонка в пуле соединений DNS-прокси (закрытие пула против выдачи/возврата соединения).
- Кэш DNS отдаёт копии адресов — исключено случайное изменение записей кэша на месте.
- При активном drop AAAA-ответы больше не протекают в nftset.

## Интерфейсы

- Авто-тест доступности IP больше не запускается для входящих интерфейсов (только для исходящих/аплинков).

## Наблюдаемость

- Захваченные домены отображаются в реальном времени в интерфейсе.

---

**Установка / обновление на Keenetic (Entware):**

```sh
opkg update && opkg install wget-ssl ca-certificates
wget -qO- https://raw.githubusercontent.com/badigit/MagiTrickle_mod_badigit/mod_badigit/scripts/install.sh | sh
```

Начиная с этого релиза обновляться можно прямо из веб-интерфейса — кнопкой «Обновить».
