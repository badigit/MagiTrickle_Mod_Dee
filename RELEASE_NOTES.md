## Что нового

- **Автообновление из веб-интерфейса**: проверка раз в сутки + кнопка «Обновить»; корректно работает и с dev-сборок (`~git…`)
- **interface-режим: долгие сессии больше не рвутся** — маршрут фиксируется на всё соединение через conntrack, вычистка IP из ipset по DNS TTL не обрывает загрузки/SSH/WebSocket
- **Детерминированный арбитраж пересечений**: во всех режимах побеждает первая группа по списку («выше = приоритетнее»)
- **direct гарантированно перебивает остальные группы**, включая установленные соединения
- Маршрут группы пересоздаётся сам, если интерфейс получил адрес/шлюз после поднятия (раньше — рестарт)
- Закрыты гонки: конфиг (единый мьютекс), пул соединений DNS-прокси, кэш DNS
- AAAA-ответы не протекают в nftset при активном drop
- Авто-тест IP не запускается для входящих интерфейсов
- Захваченные домены — в реальном времени в веб-интерфейсе
- Интеграционный netns-тест interface-режима (живой демон и трафик) + юнит-тесты арбитража

---

**Установка / обновление на Keenetic (Entware):**

```sh
opkg update && opkg install wget-ssl ca-certificates
wget -qO- https://raw.githubusercontent.com/badigit/MagiTrickle_mod_badigit/mod_badigit/scripts/install.sh | sh
```

Дальше можно обновляться прямо из веб-интерфейса — кнопкой «Обновить».
